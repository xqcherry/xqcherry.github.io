## PRG 与流密码

OTP的优点：可以实现完善保密性，安全性高
缺点：密钥和明文一样长

密码系统希望
> 用一个很短的密钥，生成一个很长的、看起来随机的密钥流
这就是 PRG（伪随机生成器）的作用


### PRG 定义

PRG 可以表示为：

```text
G : {0,1}^s → {0,1}^n
```

其中：

* `s`：种子长度
* `n`：输出长度
* 通常：

```text
s << n
```

也就是说：

```text
短种子
  ↓
 PRG
  ↓
长伪随机序列
```

例如：

```text
k = 101101
     ↓
    PRG
     ↓
101011001101010101101...
```

PRG 是**确定性函数**：

> 相同的种子一定产生相同的输出

### 流密码

**流密码利用 PRG 产生密钥流，然后与明文进行 XOR**


**区别：**

OTP：

```text
m ⊕ 真随机密钥
```

流密码：

```text
m ⊕ 伪随机密钥流
```

核心区别：

|          | OTP        | 流密码     |
| -------- | ---------- | ---------- |
| 密钥     | 真随机     | 短种子     |
| 密钥长度 | ≥ 明文长度 | 远小于明文 |
| 密钥流   | 真随机     | PRG 生成   |
| 安全性   | 完善保密   | 计算安全   |
| 实用性   | 较低       | 很高       |

因此：

> **OTP 追求信息论安全，流密码追求计算安全**
