## MySQL 的架构是怎么样的？

**MySQL 的架构共分为两层：Server 层和存储引擎层**

1. Server 层负责建立连接、分析和执行 SQL
2. 存储引擎层负责数据的存储和提取

## MySQL 的存储引擎有哪些？它们之间有什么区别？

MySQL 常见存储引擎有 InnoDB、MyISAM、Memory 等

其中 InnoDB 是默认引擎，支持事务、行级锁、MVCC 等，适合高并发业务
MyISAM 不支持事务，使用表锁，查询性能较高，适合读多写少场景

目前基本以InnoDB为主
