## Redis集群的实现原理是什么？

Redis 集群主要解决了单机内存和并发的瓶颈，它通过多个 Redis 实例组成，每个实例存储不同的数据分片

它的实现原理，可以用三个关键词来概括：**分片、Gossip 协议、去中心化**

1. 数据怎么存？

Redis Cluster 引入哈希槽，整个集群一共 16384 个槽，每个主节点负责一部分槽。
存储 Key 时：
```
Key → CRC16 → % 16384 → Hash Slot → 对应 Master
```
这样扩缩容时，只需要把部分槽迁移到新节点，不需要重新计算所有 Key 的位置

2. 节点之间怎么联系？

Redis Cluster 是去中心化的，没有中心节点
节点之间通过 Gossip 协议交换集群信息，例如：

- 节点是否存活
- 节点负责哪些槽
- 集群拓扑信息

让每个节点逐渐了解整个集群的状态

3. 客户端怎么找数据？

客户端可以连接集群中的任意节点。

如果 Key 属于当前节点负责的槽，直接返回结果。
如果不属于当前节点，节点返回 MOVED，告诉客户端正确的节点。
```
客户端 → 节点 A
          ↓
        MOVED
          ↓
客户端 → 节点 B → 返回数据
```
