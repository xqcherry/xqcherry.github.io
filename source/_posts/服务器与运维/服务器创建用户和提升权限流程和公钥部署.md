## 创建新用户

```
sudo useradd -m -s /bin/bash [name]
sudo passwd [name]
```

## 提升权限

```
sudo usermod -aG sudo [name]
```

## 部署公钥

1. 本地生成密钥对

   ```
   ssh-keygen -t ed25519 -C "your_email@example.com"
   ```

2. 部署到服务器

   ```
   ssh-copy-id user@server_ip
   ```
